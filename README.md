# Анализ зависимостей пакетов Linux

### Описание:

Проект предназначен для визуализации зависимостей между пакетами в Ubuntu. Он позволяет автоматически строить граф зависимостей по указанному пакету и сохранять его в виде изображения (Mermaid → SVG).

### Использование:

Указать имя пакета при запуске (например, adcli).
Программа скачает данные о пакетах и построит дерево зависимостей.
Результаты сохраняются в файлы:
graph.mmd — исходный Mermaid-граф;
graph.svg — визуализированный граф зависимостей.

### Стек технологий:

- Java 17
- Mermaid CLI для визуализации
- GZIP + HTTP для загрузки и распаковки Packages.gz
- File I/O для сохранения графов и изображений
